# 多维度词条随机抽卡工具

一个纯 Python 实现的多维度独立词条随机抽卡工具，面向 **二次元角色 / AI 人设 / 绘画提示词生成** 场景。支持自定义任意数量的创作维度，随机抽取各维度词条并自动拼接成可直接使用的完整文案，单次抽取或批量连抽均可。

- 原生 Python，零第三方依赖，兼容主流 Python 版本
- 纯配置化，词条数据与程序逻辑完全解耦，改配置即可增删改词条
- 支持维度优先级、词条权重、跨维度冲突检测与自动重抽、全局前缀

---

## 二、使用说明

### 1. 自定义连抽（输入 `1`）

输入 `1` 后，输入抽数即可。抽数为任意正整数，支持快捷数值：

```
── 快捷抽取参考 ──
1 = 单抽  5 = 五连抽  10 = 十连抽（也可输入任意正整数）
请输入抽数：
```

- **单抽（输入 1）**：控制台详细展示各维度词条 + 全局前缀 + 拼接文案。
- **连抽（输入 ≥2）**：结果逐段写入 `抽卡.txt`（每段一行、段间换行隔开），控制台只显示前 5 段预览、文件路径和冲突统计。

> 单次连抽上限为 1000 抽；空输入、非数字、负数、超限等异常输入都会被拦截并提示，不会导致程序报错。

### 2. 查看配置（输入 `2`）

展示当前所有维度的优先级、词条数、词条预览、冲突规则、最大重抽次数、全局前缀，以及配置修改指引。

### 3. 退出（输入 `0`）

## 三、配置说明（核心）

所有词条数据都在 `gacha_config.json` 中，改完保存后重新运行即可生效，**无需改任何代码**。

### 整体结构

```json
{
  "max_redraw": 10,
  "global_prefix": "韩国女性，单人，18岁，cosplayer，皮肤白皙细腻，写实照片",
  "dimensions": [
    {
      "name": "角色类型",
      "priority": 21,
      "entries": [
        "纯欲猫耳女仆",
        "魅魔少女",
        {"text": "神秘侠客", "weight": 80}
      ]
    }
  ],
  "conflicts": [
    ["穿粉色上衣", "正在浴室洗澡"]
  ]
}
```

### 两个核心概念（务必区分）

| 概念 | 字段 | 层面 | 作用 | 默认值 |
|---|---|---|---|---|
| **优先级** | `priority` | 维度（外部） | 决定哪个维度**先被抽取**（数值越大越先抽） | 第 1 维=21、第 2 维=22、第 3 维=23…递增 |
| **权重** | `weight` | 词条（内部） | 决定该词条在**所属维度内被抽中**的概率 | 20 |

- **优先级是「外部」的**：管的是维度之间的抽取先后顺序（数值越大越先抽，先抽的维度在冲突时优先保留）。
- **权重是「内部」的**：管的是同一个维度里，某个词条被抽中的概率（数值越大越容易抽中，0=不参与，100=最高）。

### 维度（dimensions）

每个维度是一个对象，包含：

- `name`：维度名称（必填，如「角色类型」「发型发色」）
- `priority`：维度优先级（选填，不写则按顺序自动 21、22、23…）
- `entries`：该维度的词条列表

**新增维度**：复制一个维度对象，改 `name` 和 `entries` 即可，自动适配抽取、权重、冲突、拼接全流程。

### 词条（entries）

词条支持两种写法，可混用：

1. **纯字符串**（使用默认权重 20）：
   ```json
   "魅魔少女"
   ```

2. **对象写法**（自定义权重）：
   ```json
   {"text": "撑桌托腮+侧眸浅笑+眼神娇媚", "weight": 80}
   ```

> 权重取值范围 0-100，越大越优先。想「高出场」的词条给高权重（如 80-90），想「低出场」的词条给低权重（如 5-10）。兼容旧写法「高/中/低」（映射为 高=70 / 中=默认 / 低=5）。

### 全局前缀（global_prefix）

固定插入每段拼接文案**最前面**的文本，常用于描述画质、人物基础设定等，例如：

```json
"global_prefix": "韩国女性，单人，18岁，cosplayer，皮肤白皙细腻，写实照片"
```

- 留空或不写该字段，则不加前缀。
- 拼接结果示例：`韩国女性，单人，18岁，cosplayer，皮肤白皙细腻，写实照片，魅魔少女，浅金渐变+樱花粉挑染+长直发+空气刘海+珍珠发夹，…`

### 冲突规则（conflicts）

冲突是**跨维度**的词条互斥，用于避免拼接后出现语义矛盾、场景冲突的组合。

- 把互斥的词条写进同一组数组，**组内任意两个词即互斥**（一词对多词互斥只需写一条）：

  ```json
  "conflicts": [
    ["穿粉色上衣", "正在浴室洗澡"],
    ["雪落无声", "清凉夏装"]
  ]
  ```

- 冲突时自动重抽对应维度（保留优先级高的维度），最多重抽 `max_redraw` 次（默认 10），避免死循环。
- **注意**：同维度的词条一次只抽一个、不会同时出现，所以「同维度冲突」是冗余的，无需配置（程序启动时会给出提示）。

## 五、常见问题

**Q：Windows 控制台中文/emoji 乱码？**
A：程序已自动尝试切换 UTF-8 输出。若仍有乱码，可在运行前执行 `chcp 65001`。

**Q：如何批量更新词条？**
A：直接编辑 `gacha_config.json` 里的 `entries` 列表，增、删、改词条文本即可，保存后重新运行即生效。

**Q：想给某维度整体调高/调低出场？**
A：调整该维度的 `priority` 数值即可（影响抽取顺序）；想调维度内某个词条的概率，改该词条的 `weight`。
